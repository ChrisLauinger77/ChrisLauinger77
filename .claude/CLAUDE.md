## Learned rules
- Always write git commit messages in Conventional Commits format (type: description), regardless of the repository's existing style.
- Do not add coding-tool trailers to commits; keep commit messages free of them.
- Never add the 'Generated with Claude Code' attribution or similar AI credit to GitHub issues, PRs, or other posted content.
- Coding prompt should always be in English
- Double quotes are preferred over single quotes.
